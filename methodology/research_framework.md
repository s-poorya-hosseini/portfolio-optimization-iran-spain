# Research Framework

## Objective

This research evaluates the comparative performance of classical portfolio optimization models and machine-learning-assisted allocation frameworks across heterogeneous financial markets.

The empirical analysis focuses on:
- Tehran Stock Exchange (TEDPIX)
- Spanish Equity Market (IBEX 35)

---

## Classical Optimization Models

The study implements Markowitz Mean-Variance Optimization, including:

- Minimum Variance Portfolio
- Maximum Sharpe Ratio Portfolio

---

## Machine-Learning-Assisted Framework

The computational framework integrates:

- Ridge Regression
- Mixed-Integer Programming (MIP)

The objective of the framework is to combine multiple financial information layers into a structured portfolio allocation process.

---

## Computational Environment

The project was implemented using Python-based quantitative research workflows, including:

- Rolling-window backtesting
- Portfolio rebalancing
- Cross-market comparative analysis
- Quantitative portfolio evaluation
